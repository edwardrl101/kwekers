# Interactive demo repository audit

This audit records the source-of-truth review performed before building the demo.

1. **Agent entry point:** `starter.agent.Agent`. The evaluator constructs it with the catalog path, calls `reset(session_id, user_profile)`, then `respond(session_id, user_message, turn, top_k)`.
2. **Response schema:** `message`, `ask_attribute`, ten `{parent_asin}` recommendations, and zero/default or optional LLM `usage` token counts.
3. **Session state:** `Agent._sessions` stores the profile hash, `src.dialog.SlotState`, category context, active constraints, shown-ASIN set, and optional confidence. Overrides demote earlier constraints to soft state.
4. **Retrieval:** `src.retrieval.BM25Route` uses in-memory SQLite FTS5, six weighted catalog fields, and a phrase → AND → OR strictness cascade. It supplies the only 500-item admission pool.
5. **Exact evidence:** `src.exact.ExactRoute` indexes feature/detail strings, materials, and budget ranges. Supported accumulated constraints are intersected; unsupported constraints supply no evidence and do not veto.
6. **Normalization / LLM:** `src.dialog` is the default regex-first parser. `src.normalize` and `src.llm` provide optional OpenRouter normalization, override detection, and copy generation, all default-off and fail-closed.
7. **Freshness:** the per-session `shown` set excludes previous results. Recognized intent overrides clear it before retrieval.
8. **Ranking:** `_fuse_bm25_pool` rank-normalizes the BM25 base, adds `0.35` exact membership and `0.10` category-bucket membership, and uses original BM25 rank as the tie-break. Dense weight is `0.0` in production.
9. **Metrics:** the checked-in `results.json` is the weak starter run and is stale for current production. The current checkout was re-evaluated after the deterministic SQLite ASIN tie-break: score `0.891084`, Hit@10 `1.0`, MRR `0.707615`, MTTC `2.06` over 200 sessions, matching `tests/test_frozen_baseline.py`. Older reports stating `0.891111` predate that tie-break. Evaluations are generated by `evaluator/local_evaluator.py` and `scripts/eval_cv.py`.
10. **Non-production experiments:** dense retrieval/rescoring is implemented but disabled; hard category filtering, near-duplicate suppression (`src/dedup.py`), exact-set promotion, and rotating question policy are not called by `Agent.respond()`.
11. **Existing UI/API:** none was present.

## Minimum integration selected

`demo_server.py` serves three static files and exposes `POST /api/chat` and `POST /api/reset`. It calls the real production Agent. Request-scoped wrappers observe the query, route results, and fused order without a second route call or any ranking mutation; catalog metadata is joined only after the response. No dependency was added and evaluator behavior is unchanged.
