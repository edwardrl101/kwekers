# Five-fold cross-validation baseline

## Scope

This report records the first grouped, scenario-stratified five-fold stability
check for the Kwekers public development set. Cross-validation compares frozen
Agent configurations; it does not train a model and is not an untouched test
after its results influence development.

## Fold construction

The committed `data/cv_folds.json` was generated by
`scripts/build_cv_folds.py` with seed `kwekers-cv-v1`.

- Public sessions: 200.
- Target ASINs found in the catalog: 200.
- Repeated target ASINs: 0.
- Exact normalized-title groups with more than one target: 0.
- Variant-sensitive token-Jaccard title groups at thresholds 0.95, 0.90, and
  0.85: 0.
- Selected grouping threshold: 0.90, with color/gender/size/numeric variant
  tokens required to match.
- Resulting groups: 200 singleton groups.
- Fold size: 40 sessions each.
- Per-fold composition: 16 buying, 16 browsing, 6 intent override, and 2
  boundary sessions.

The grouping machinery still joins repeated targets and connected conservative
title families, so future datasets cannot split those declared groups across
validation folds. The manifest stores every sample's group and a canonical
SHA-256 digest. Tests enforce determinism, disjointness, complete coverage,
group isolation, scenario counts, and loud failure on duplicate sample IDs.

## Baseline results

Measured locally on 2026-08-30 with dense retrieval disabled:

| Configuration | Mean score | Population SD | Worst fold | OOF score | OOF Hit@10 | OOF MRR | OOF MTTC |
|---|---:|---:|---:|---:|---:|---:|---:|
| Production no-dense | **0.877011** | 0.019642 | 0.840232 | **0.877011** | 0.995000 | **0.690702** | **2.385000** |
| BM25-only freshness | 0.862811 | **0.013850** | **0.841952** | 0.862811 | 0.995000 | 0.648038 | 2.455000 |

Production no-dense fold scores were:

```text
0.890414, 0.840232, 0.896726, 0.879643, 0.878039
```

BM25-only fold scores were:

```text
0.868423, 0.841952, 0.881580, 0.852863, 0.869238
```

Production improves aggregate MRR and MTTC while preserving Hit@10. Its
advantage is positive in four of five folds; BM25-only is higher by 0.001720 in
fold 1. The evidence supports retaining the production configuration, while
the fold spread shows why future small gains should not be accepted from a
single aggregate score.

Generated `results_cv_*.json` files remain ignored. They contain per-session
results and traceable code, data, catalog, manifest, runtime, and configuration
metadata.

## Commands

```bash
python scripts/build_cv_folds.py
python scripts/eval_cv.py --validate-only
python scripts/eval_cv.py --config no-dense --folds all
python scripts/eval_cv.py --config bm25-only --folds all
```

The existing fixed `data/eval_split.json` remains unchanged. Its holdout was
partially consumed during Day 3 configuration selection and should not be used
for every small change.
